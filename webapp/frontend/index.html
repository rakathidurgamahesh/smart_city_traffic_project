    About this project

    Sensors write readings to a shared SQLite database (DBMS: ER model + SQL aggregation). A Python harmonic regression forecasts hourly congestion (Python). Roads form a weighted graph and Dijkstra finds least-congested routes (ADSA). The Java console app (OOPJ) and this Flask + JavaScript dashboard both read the same data.
